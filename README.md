# 🏆 Tournament Lab

Tournament Lab is a desktop application for creating, managing, simulating, and analyzing tournament systems.

The goal is to provide a flexible environment where organizers, players, and developers can experiment with different tournament formats while maintaining a clean and intuitive user experience.

---

## ✨ Planned Features

- Create tournaments
- Import participants
  - TXT
  - CSV
  - Excel (future)
- Swiss System
- Round Robin
- Single Elimination
- Double Elimination
- Custom Tournament Systems
- Tournament Simulations
- Statistics & Analytics
- Charts & Visualizations

---

## 🛠️ Technology Stack

- Python
- PySide6 (Qt)
- JSON
